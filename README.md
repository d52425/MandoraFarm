# マンドラゴラ農園 (MandoraFarm)

魔女が魔女植物を育てる、ブラウザで遊べる3Dアイソメトリック箱庭農場ゲームのプロトタイプです。

**Play: https://d52425.github.io/MandoraFarm/**

## 遊び方

- 畝をクリックすると魔女が歩いて行って、選んだ種を植えます
- 作物が育ったら、クリックして収穫するとコインと経験値が入ります
- 「🪄 成長促進魔法をかける」で育っている作物をぐんと育てられます
- レベルが上がると種屋で買える種が増えます：ヘンルーダ (Lv2) → ベラドンナ (Lv3) → ダチュラ (Lv4) → ジギタリス (Lv5) → トリカブト (Lv6) → マンドラゴラ (Lv7, 最高Tier)
- マンドラゴラを引っこ抜くと叫びます（音が出ます）
- コインでゴーレムを雇うと、自動で植え付けと収穫を手伝ってくれます
- コインが尽きて詰んだときは、種屋のおばあちゃんがヨモギの種を分けてくれます

## 技術メモ

- 単一の静的 `index.html`（Three.js インライン同梱）で動作し、GitHub Pages で公開しています
- 本格版の構想：Vue 3 + TresJS / Three.js、ロジックは2Dグリッド、描画は3Dアイソメ
